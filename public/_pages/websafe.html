Web-Safe Colors — 216-Color Hex Chart

The complete 216-color web-safe palette. Every swatch shows its hex code and RGB values, with a link to the color's full detail page.

The 216-color web-safe palette uses only the values 00, 33, 66, 99, CC, FF for each RGB channel — guaranteeing the same rendering across all 256-color displays.

Web-safe colors were essential in the 1990s when monitors and operating systems could dither or shift colors unpredictably. Modern displays render the full 16.7-million-color sRGB gamut, so the web-safe palette is no longer required — but it remains useful for email HTML, legacy systems, and any context where exact color rendering must be guaranteed.
